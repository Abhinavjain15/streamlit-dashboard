# Stock Tracker Dashboard

A quick Streamlit app to track stock prices and visualize trends.

## Features

- 📈 Search any stock by ticker symbol
- 📅 Select custom date range for analysis
- 📊 View historical data in a table
- 💹 Interactive charts for closing prices and trading volume

## Setup

### Requirements
- Python 3.x
- Streamlit
- yfinance

### Installation

```bash
pip install -r requirements.txt
pip install streamlit
```

### Run Locally

```bash
streamlit run stock-tracker.py
```

## How to Use

1. Enter a stock ticker symbol (e.g., AAPL, GOOGL, MSFT)
2. Pick your start and end dates
3. View the stock data and charts

## Deploy

Push to GitHub and deploy on [Streamlit Cloud](https://share.streamlit.io/)
